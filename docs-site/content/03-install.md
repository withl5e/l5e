# Install

- Generator: `npm create l5e my-app -- --template basic` (or `--template minimal`).
- Manual: add `@withl5e/l5e` peer with `react`, `react-dom`, `vite`.
- Run: `pnpm dev` (or the equivalent for your package manager).
