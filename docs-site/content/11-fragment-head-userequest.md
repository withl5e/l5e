# Fragment, Head & useRequest

- `Fragment`: explicit alternative to `<>` shorthand — prefer it for consistency.
- `Head`: pushes nodes into `<head>` with a priority slot (critical / high / medium / SEO).
- `useRequest()`: read the current `RequestInfo` inside any component (url, query, headers, cookies).
